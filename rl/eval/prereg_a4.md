## 1. Гипотезы

- **H0-A4 (диагностика до обучения, не правило остановки).** При новом казначейском правиле ex-post оракул по
  библиотеке неучащихся политик значимо лучше C* на holdout (запас для адаптивной политики есть).
- **H1-A4 (главная, гейт G-A4).** Обученная структурная политика лучше **C\*** по хвосту прибыли на ОБОИХ
  отложенных наборах: (а) 30 экземпляров A3 и (б) ≥ 30 НОВЫХ экземпляров того же генератора с другим seed.
- **H2-A4 (строгий контроль G-strict).** То же против строгого чемпиона C\*\* — лучшей на валидации неучащейся
  политики из пула {лучшее правило, ключ CP-SAT, ключ ГА с тёплым стартом CP-SAT, IIP, C\*, LA\*} (§4). Выигрыш,
  который даёт одна строка правил на тех же признаках, засчитывается правилу, а не обучению (урок A3).

## 4. Политики сравнения (все при новом казначейском правиле и налоге)

1. **best_rule** — лучшее из 7 правил по CVaR₀.₁(Π) на валидации (128), без ходов.
2. **CPSAT**, **GA** — ключи A3 (`keys_a3.json`) для набора A3; для F — тот же протокол (CP-SAT 60 с с подсказкой
   лучшего правила по F, ГА 30 с с тёплым стартом CP-SAT); без ходов.
3. **IIP** — «инвестируй, если окупается» (C++ `invest_eval` на валидации 128; правило применения A3).
4. **C\*** — лучшая на валидации (балл s, §5) политика библиотеки A3 `library()` (сетка 14 эвристик × {без покупки,
   кандидат 0/1/2 в неделю 0} = 56) **при погашении линии излишком кассы по умолчанию** — «лучшая структурная
   эвристика + погашение линии». Контроль непрерывности: **H\*_A3** — эвристика H* из `champions_a3.json` без
   повторного выбора.
5. **LA(θ)** — неучащаяся «жадная по последствиям» политика на признаках A4 (§6): купить кандидата c, если
   ΔCVaR₀.₁(Π) кандидата > θ, ΔE[Π] > 0, ΔP(разрыва) ≤ 0 и запас ликвидности после транша > 0; «срочный первым» при
   срочном заказе; сверхурочные, если прогнозная чистая выгода > θ; субподряд, если > θ; θ ∈ {0; 0.05; 0.2} % V.
   **LA\*** — лучшая из трёх на валидации.
6. **C\*\*** (строгий чемпион) — лучшая на валидации из 1–5.
7. **oracle_bound** — ex-post максимум прибыли по библиотеке ∪ LA на КАЖДОМ сценарии (недостижимая граница).
8. **RL** — по сиду лучший по валидации чекпойнт; кандидат гейта — сид (и вариант, §7) с лучшим баллом валидации.

## 5. Метрики

Как A3 §5: Π — прибыль после налога за 26 недель; C_min — минимум netCash; разности в **% стоимости портфеля V**:
ΔCVaR₀.₁(Π) (главная), ΔCVaR₀.₀₅(C_min), ΔE[Π]; по экземплярам — **IQM, парный бутстреп-ДИ 95 % (B = 2 000,
seed 1), Уилкоксон**, доля экземпляров с выигрышем. Балл валидации s = [ΔCVaR₀.₁(Π) + 0.5·ΔCVaR₀.₀₅(C_min)]/V.
Экстренное реагирование (shock): Δ времени восстановления, Δ просрочки, Δ потерь прибыли и min-кассы от шока
(шок − двойник), доля шоков, где политика лучше; ДИ — бутстреп по парам. Интерпретация — ходы по видам, по типу
эпохи (неделя/шок), по режиму HMM, по классу экземпляра; отдельно инвестиции vs сверхурочные vs субподряд.

## 7. Обучение (фиксируется до запуска; `rl/train/train_l4.py`)

- Только экземпляры A3 и обучающие сценарии. Действия 13 с масками SimEnv; MLP актёр [256, 256] и критик [256, 256].
- **BC от C\***: траектории C* на 48 сценариях/экземпляр/пул (base, shock), 10 эпох, сглаживание 0.05 по допустимым.
- **PPO собственной реализации с доверительной областью**: clip 0.1, **target KL 0.01** (эпохи обновления
  прерываются при KL > 1.5·цели), lr 3·10⁻⁵ (дообучение), ≤ 4 эпох, минипакет 4 096, энтропия 0.001, норма
  градиента 0.5, γ = 1, преимущество = r − V(s).
- **CVaR по пакету общих сценариев (Рокафеллар–Урясев)**: итерация = для каждого экземпляра пакет из B = 32
  обучающих сценариев (половина экземпляров — пул base, половина — shock, по итерациям чередуется), эпизоды
  пакета — на ОДНИХ И ТЕХ ЖЕ сценариях для политики и эталона C*; η — α-квантиль прибыли текущей политики по пакету;
  терминальная награда эпизода
  r = 100/V·[(1−λ)(Π − Π_C*) + λ((η − Π_C*)⁺ − (η − Π)⁺)/α + w_c(min(0, C_min) − min(0, C_min,C*))],
  α = 0.1, w_c = 0.5. Эталонные члены — контрольная переменная, не зависящая от действий (несмещённо).
- **Варианты** (оба предрегистрированы; кандидат — вариант с лучшим средним по сидам баллом валидации):
  **A**: λ = 0.5; **B**: λ = 1 (чистый CVaR по пакету).
- **Сиды**: 1, 2, 3 в каждом варианте. **Бюджет**: ≥ 5·10⁵ и ≤ 1.5·10⁶ решений на сид, валидация каждые
  ~10⁵ решений; итого ≥ 3·10⁶ решений (≥ 2·10⁶ требуется).
- **Ранняя остановка и чекпойнт** — только по баллу валидации к C* (128 сценариев × 30 экземпляров A3,
  детерминированная политика); набор F и holdout при обучении не используются.

## 8. Гейт

Для набора X ∈ {A3, F}, стресс base, holdout 200 сценариев:

- **G-A4(X)**: кандидат RL против C\*: IQM ΔCVaR₀.₁(Π) > 0 **и нижняя граница 95 %-ДИ > 0**, IQM ΔCVaR₀.₀₅(C_min) ≥ 0,
  и IQM ΔCVaR₀.₁(Π) > 0 у всех 3 сидов кандидатного варианта.
- **G-strict(X)**: то же против C\*\*.
- **`gate_pass` (API, публикация ONNX, `moves[]` в `/api/schedule`) = G-A4(A3) ∧ G-A4(F) ∧ G-strict(A3) ∧ G-strict(F).**
- Отдельно (не гейт): к лучшему правилу, ГА, CP-SAT, IIP; стрессы crisis/quantile/joint/shock — отдельные
  утверждения; экстренное реагирование.

Если гейт не пройден — точный диагноз с числами и следующий эксперимент; политика не публикуется.

## 9. Поправки

**Ф1 (2026-10-24, до обучения; фиксация набора F).** Набор F сгенерирован (`python -m rl.bench.instances_a3 --seed
20261024 --out rl/bench/data/instances_a4f --prefix a4f`; генератор получил только параметры seed/out/prefix, логика
та же — проверка: перегенерация a3-s00 и a3-m13 с seed 20261023 на текущей БД совпадает с замороженными JSON
побитово, кроме нового ключа `fin.auto_repay`). SHA-256 (16 знаков): конкатенация `a4f-*.json` 73d26b3b1951c4d2,
`index.json` 8ba98a77e5bdf479, `instances_a3.py` 19750c53b8e3f924. 30 экземпляров: 512–4 213 джоб, тесная касса — 15.
Ключи CP-SAT/ГА для F: `rl/results/a4/keys_a4f.json` (30/30 FEASIBLE, ГА 30/30).

**П1 (2026-10-24, до обучения; базы и H0-A4 ещё считаются, holdout RL не трогался).** Добавлен третий
предрегистрированный вариант обучения **C — «лоза» (TRPO vine, Schulman et al. 2015 §5.2)**: ствол — детерминированная
текущая политика на B = 32 обучающих сценариях экземпляра; в одной случайной точке решения каждого эпизода (≥ 2
допустимых хода) — ветви по ВСЕМ допустимым ходам, каждая доигрывается текущей политикой на ТОМ ЖЕ сценарии (CRN;
повтор префикса ходов детерминирован — проверено); Q̂(s,a) = 100/V·[(1−λ)Π_a + λ(η − (η − Π_a)⁺/α) + w_c·min(0,
C_min,a)], λ = 0.5, η — α-квантиль прибыли ствола по пакету; обновление — градиент по всем действиям
Σ_a π(a|s)(Q̂ − Σ_a' π_old Q̂) с доверительной областью KL(π_old‖π) ≤ 0.01 (lr 1·10⁻⁴, ≤ 20 эпох). Бюджет C — по
числу смоделированных решений (ствол + ветви + повтор префиксов): ≥ 2·10⁶ и ≤ 6·10⁶ на сид, валидация каждые 5·10⁵.
Причина: в A3 терминальная награда PPO давала редкий знакопеременный сигнал условных ходов (диагноз A3 §7 а);
парные ветви на общих сценариях — стандартное снижение дисперсии оценки преимущества. Правило выбора кандидата
(вариант с лучшим средним баллом валидации, затем сид) и гейт §8 — без изменений; варианты A, B, C — все отчитываются.

**П2 (2026-10-24, там же).** Вход RL = 80 + one-hot хода C\* + one-hot хода **LA\*** экземпляра (106) во всех
вариантах. Причина: LA\* входит в пул строгого чемпиона C\*\*; «подсказки» обеих неучащихся политик вычислимы онлайн,
и RL учится, в каких состояниях какой следовать или отклоняться от обеих. Учитель BC и эталон награды — C\*.
