# G4 — экран «Агенты», структурные ходы, диф плана, RL в мастере, петля на карте, палитра, MENTAT

> Отчёт агента G4 по [UX-V2 §4.7–4.10, §7 G4, §8](../UX-V2.md) поверх волны A ([A1-rl-wave.md](A1-rl-wave.md)).
> Дата: 2026-10-23. Только `src/` и `docs/`; `backend/`, `rl/`, `src/lib/api.ts`, `src/brand` не тронуты. Не закоммичено, версия не поднималась.
> Главная честная граница: **ни одна политика RL не прошла гейт §7.4 — чемпион = лучшее правило** (A1 §5). UI это
> говорит прямо везде, где появляется RL; выигрыши без ДИ не показываются, игры — в состоянии «в плане», без чисел.

### Исправления трёх падавших тестов из незавершённой попытки
- `commandIndex` ×2: ключевые слова теперь ранжируются как начало слова (оценка 2) — экран «Агенты» с ключом `rl` по запросу «rl» идёт перед узлом карты (тест был прав по смыслу). Второй тест ошибочен: запрос «а» (кириллица) не входит в «Переключить тему» — ожидание исправлено на фактические группы `screen`, `node` плюс проверка порядка внутри группы.
- `diffModel` ×1: изменения сортируются по времени (`at`); «добавлено» в 30 ч стоит раньше второго «перенесено» в 34 ч — ожидание в тесте было арифметически неверным, исправлено.
- Попутно найдено и исправлено: `touches()` совпадал по `op_ids` без учёта заказа, а операция техкарты общая у всех заказов изделия — ход одного заказа задевал все. Теперь все заданные измерения целей — через «И» (+ тест).

## 4. Чего не хватает в API (выведено на фронтенде) и отложено

Поля/эндпоинты, которых нет в `src/lib/api.ts` (зона другого агента) — обходы:
1. `POST /api/runs/:id/moves/decide` — нет → `decisionsStore` (сессия) + `applyMoves` (фронтенд строит «после» по снимкам `release_hours / machine_id / outsourced / n_batches`).
2. Результаты V4/V5 и вердикт гейта — эндпоинта нет, в `RlStatus` нет `champion/gate` → снимок JSON с бейджем даты (`benchData.ts`). Нужен `GET /api/rl/results` (или поля `gate`, `champion`, `v5_best` в `/api/rl/status`).
3. `agent_guardrails` — отдельного API проекта нет → общий KV `PUT /api/prefs/agent_guardrails`; в `ScheduleParams` нет `agent: { enabled, guardrails }`.
4. `RlEval` без ДИ и без сценарной оценки → карточка честно «без ДИ».
5. Атрибуция `MoveImpact` — на пакет, не на ход (A1 §6): строки ходов подписаны «итог пакета не складывается из строк».
6. «Цена ограничения» лимитов пакета (PID-лагранжиан) не отдаётся → подпись «появится, когда бэкенд её отдаст».
7. Нет потока прогресса агента → петля на карте не пульсирует «во время реального прогона», только по состоянию узла.

Отложено:
- Реальные `moves[]` от L2 не проверены в браузере: политика не опубликована, сервер отвечает «RL недоступно»; путь `agent`/`agent-empty` покрыт тестами `movesSource`.
- «Маршрут» сделан цепочками по заказам, не дифом графа `process-graph` на канвасе.
- Полная `GuardrailsCard` в шаге 5 мастера и в панели узла [6] — в мастере сводка «разрешено N видов · изменить →», карточка — на «Агентах».
- Гистограмма прибыли до/после с хвостом α в обосновании (`ProfitDistribution`) — нет сценарных распределений в `MoveImpact`.
- Игры (V6): цена анархии, Штакельберг, выученные цены против двойственных LP — только формулы.
- MENTAT: ответы локальной LLM, свой вопрос, «почему» на конкретное число результата.
- Действие узла «Переобучить политику» убрано: обучение — на стенде `rl/`, не в продукте; честнее ссылки на «Агенты».
