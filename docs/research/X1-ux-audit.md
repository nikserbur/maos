## 0. TL;DR — вердикт

1. **Красиво, но не связно.** Токены и бренд «Конструктивный Кандинский» настоящие и качественные (`tokens.css` — 180 токенов, OKLCH, глифы), но экраны собирались разными руками: **четыре параллельных UI-кита** (`optimization/kit`, `nsi/kit`, `plan/ui.tsx`, `src/ui`) с тремя `Segmented`, тремя `EmptyState`, тремя `Skeleton`, двумя `ScreenHeader`; **279 inline-`style={{}}`** (52 только в `RoutingSchemeEditor.tsx`), **~300 литералов `font-size: Npx`** мимо шкалы (`scene.css` 60+, `forecast.css` 30+, `optimization.css` 25+), **27 эмодзи** в UI (🏭 📊 ⚙ ⏹ ⛶ ✓ ⚠).
2. **«План» перегружен тремя слоями шапок.** На экране результата над содержимым висят: TopBar (48) + PipelineStrip (36) + заголовок экрана с 3 абзацами (≈150) + «Шаги» + «Шаг 7 из 7» + TOC-пилюли. До первой цифры ~330 px. И **TOC-пилюли прилипают не под шапкой, а посреди контента** и просвечивают (`plan-screen.css:208`, `top: calc(--topbar-h + --pipeline-h + 4px)` считается от скролл-контейнера `.plan`, который сам начинается под полосой) — S1, см. `img/X1-plan-kpi.jpg`.
3. **Конструктор НСИ (техкарта)** — другой продукт: модал на весь экран, узлы в один ряд без обзора и зума, обрезанные подписи, декоративные пунктиры «IDEF0» ничего не несут, правая панель 280 px на inline-стилях с **четырьмя** primary-кнопками. S1 по иерархии.
4. **Графики не образуют систему.** 14 chart-компонентов, 6 разных реализаций осей/сетки/подсказки; пунктирная сетка в Аналитике (анти-паттерн), подписи цветом ряда (QueueChart — киноварный моно-текст поверх линии), 12 цветов на Ганте при палитре в 8 слотов (цикл через `--chart-other`), статусная зелень на «загрузке» в LoadBars, два фильтра **внутри** карточек графиков в Аналитике, сетка 44/32/24/20 px для чисел без единой шкалы.
5. **Три падения на проходе**: Мониторинг (`ForecastScreen.tsx:213` — `p.fit.aic_normal.toFixed` на undefined → ErrorBoundary на весь экран), «Maximum update depth» в `InfoTip` при размонтировании KPI результата плана (`src/ui/InfoTip.tsx:70`, floating-ui ref), `validateDOMNesting <div> в <p>` (`ObjectiveStep.tsx`, `Segmented` внутри `<p>`). Плюс результат плана **теряется при перезагрузке** (planStore в памяти; история есть, но «Последний результат» пуст; строки истории не открываются).
6. **Схема**: мировой уровень — яркая зелёная карта OpenFreeMap «liberty» внутри чернильного шелла (`WorldMap2D.tsx:27`), в тёмной и светлой теме одинаково; инспектор справа — пустые 320 px с одним селектом «Просмотр»; панель симуляции — на эмодзи.
7. **Акценты разбалансированы**: на одном экране до 4 primary-кнопок (конструктор), «Портфель» имеет две одинаковые CTA «Найти робастное решение» на пустом состоянии, в Плане CTA «Запустить…» и «Далее →» равной массы.
8. Что хорошо и не трогать: экран «Портфель» (гистограмма D2, Парето, карточка «для сравнения»), экран входа (пейзаж ГА + карточка), карта методологии (композиция, легенда, панель узла), ParamField/ProvenanceBadge как паттерн, PipelineStrip как идея.

Приоритет G3 — §7: Tier 1 = План (расчистка + фикс TOC/состояния) · конструктор НСИ · единая chart-система; Tier 2 = один UI-кит + связность/акценты; Tier 3 = полировка.

## 7. Системный обзор (кросс-экранно)

**Типографика.** Шкала задана (`--fs-11…44`), но используется мимо: ~300 литералов `font-size` в CSS фич (`scene.css` 60+, `forecast.css` 30+, `optimization.css` 25+, `scenario-compare.css` 30+, `workflow-builder.css` 15), значения 8 / 9 / 9,5 / 10 / 10,5 / 11,5 / 12,5 / 14,5 / 15 / 18 / 19 / 22 / 26 px — 13 «серых» размеров вне шкалы. Заголовки экранов: Unbounded 20 (ScreenHeader) / 26 (План `plan.css:39`) / 20 600 Onest (НСИ) / 20 Unbounded (Админ) — четыре варианта. Числа-герои: 44 (План hero, Analytics first pin) / 32 (`kpi-hero`) / 24 (`pl-tile__v--md`, `sc2-qtile`) / 22 (`optimization.css:146`) / 20 (`ParamField`) — пять ярусов, нужно три (44 герой · 24 плитка · 16 inline). `tabular-nums` стоит на герое (`kpi-hero`) — dataviz просит пропорциональные цифры на крупных одиночных числах.

**Ритм.** Шкала 4-pt есть, но поля: `gap: 14px`, `padding: 12px 14px`, `10px 12px`, `6px 8px` — в `scenarios-v2.css` 17 значений вне `--space-*`. Карточки: `--radius-lg` 10 (План) / `--radius` 6 (Сценарии) / 2–3 px (НСИ-таблица, Админ) / pill — три дилекта радиусов, A1 это уже фиксировал, не исправлено.

**Цвет — три системы сталкиваются.** (1) Цвета блоков `--block-1…8` (bone / ультрамарин / киноварь / охра / микс / фиолет / вердигрис / sky) — на чипах, полосе, левых штрихах карточек. (2) Интенты `--status-*` (зелёный / янтарь / серый / красный / синий). (3) Палитра графиков `--chart-1…8` (ультрамарин / охра / вердигрис / киноварь / sky / фиолет / лимон / серый). Столкновения: блок [4] «Решения» = охра = `--chart-2` = «CVaR ▲» = «узкое место» = «стресс-режим» = «устарело ▲» — **охра означает шесть вещей**. Киноварь = блок [3] «внутренние условия» = риск/хвост = `--chart-4` = ошибка. Вердигрис = блок [7] = «оценено» = «ок» = `--chart-3`. Правило для G3: блоки — только на `BlockChip`/полосе/штрихе карточки; статусы — только с глифом; графики — только `--chart-*`; охра на экране — только «цель/выбранное» (▲), никогда «предупреждение» (для него `--status-setup`, он чуть другой, но различие незаметно → в светлой теме нужно разводить сильнее).

**Консистентность компонентов.** Заголовки: `ScreenHeader` (opt kit) / `ScreenHeader` (nsi kit) / `plan__head` / `adm__head` / `sc2-head` — 5. Сегменты: `Segmented` (opt kit, clip-path индикатор) / `Segmented` (plan/ui.tsx) / `an__seg` (Analytics CSS) / `PillTabs` (nsi) — 4. Чипы: `Chip` (plan) / `StatusChip` (opt) / `pl-chip` / `sc2-chip` / `wz-badges` / `ProvenanceBadge` / `BlockChip` — 7 стилей. Пустые состояния: 3 реализации. Error: `ErrorBoundary` — хорошо оформлен, но **ловит три реальных падения** (Мониторинг, InfoTip, см. §0). Empty: хороши в Портфеле/Агентах; плохи — инспектор Схемы (пусто), сравнение сценариев (абзац без диаграммы), Аналитика без плана (есть). Hover/focus: `--halo` везде — хорошо; у строк таблиц НСИ/истории нет указания кликабельности.

**Моушн.** `rise()` ступенчатое появление, `pl-seg__ind` clip-path, `--dur-flow` на карте — уместно. Лишнее: `an__pin:hover translateY(-1px)` на информационных плитках (они не кнопки); нет анимации перехода между шагами мастера (контент «прыгает»).

**Иконография.** `shell/icons.tsx` — набор есть, но 27 эмодзи и ~20 юникод-стрелок/глифов (`⇄ ↗ ⭳ ⛶ ▸ ▾ ＋ ←`) как иконки в тексте кнопок; «＋ Новый план» использует полноширинный плюс U+FF0B. Правило: иконки только из `Icon`, глифы ● ▲ ■ ○ ◆ — только для состояний.

**Русская копия.** Жаргон без «почему»: «прокси CRPS», «skill к наивному −469 %», «E − λ·σ», «ключ = 0,56·срок + 0,22·наладка + 0,09·входы + δзаказа», «HAC-регрессия §2.4», «pass-through b^π = 1 [К]», «Лаплас ν=20 · n=30», «рекурс», «PoL(L_min)». Есть `InfoTip`-реестр из 71 формулы — но подписи полей сами по себе остаются шифром. Правило: подпись = человеческое («Качество прогноза против “как вчера”»), код/формула — в «i». Смесь регистра: `Α ХВОСТА` (греческая Α в caps выглядит как «А»), «Макс. доля изделия» vs «МАКС. ДОЛЯ ИЗДЕЛИЯ». Тире: встречаются «-» вместо «—» в чипах (`cvar · 11 изделий`), минусы «−» — правильно через `MINUS` в `format.ts`, но `h1()`/`toFixed` в Плане/Аналитике обходят форматтер (`v.toFixed(1)` в `PlanResult.tsx:25`, `LoadBars.tsx:8`, `QueueChart.tsx`, `AnalyticsScreen.tsx:25`).

**A11y.** Контраст текста — по токенам ок (A6 посчитан). Проблемы: «i»-кнопки 16×16 (`infotip.css:33`) и чипы 18 px (`fields.css:10`) — хит-таргет < 32; чекбоксы истории 14 px; пилюли TOC 26 px; `Segmented` в `<p>`; таблицы без `scope`/сортировки; графики: `role="img"` + aria-label есть у FanChart/FundBar, нет у TimeChart/QueueChart/Gantt/Sankey; нет «таблица-двойник» ни у одного графика; клавиатура: TimeChart ←/→ есть, Gantt/Queue — нет.
