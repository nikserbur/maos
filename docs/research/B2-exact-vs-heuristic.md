# Точная модель CVaR (Rockafellar–Uryasev, LP через HiGHS) против эвристики Стадии 2

Прогон 2026-10-20 на `maos.db` (Ливенский насосный завод: 82 изделия, 39 типов РЦ), N = 300 сценариев (CRN — одни и те же
сценарии для обоих методов), `POST /api/optimize` с `compare_exact: true`. Вогнутая выручка g(q) аппроксимирована
кусочно-линейно (≥16 отрезков на криволинейный участок) — LP без бинарных переменных; макс. ошибка PWL ≈ 95 тыс. ₽
(≈0,03 % целевой функции). Округление до партий — отдельной строкой.

Теневые цены мощностей (₽ на час, LP-двойственные — точный сигнал теории ограничений), топ-3 при CVaR:
wct-02-03 ≈ 105,9 тыс., wct-02-04 ≈ 100,6 тыс., wct-02-10 ≈ 95,3 тыс.

**Вывод для диплома:** перебор ~120 эвристических кандидатов систематически недобирает ~20 % целевой функции;
разрыв подтверждается на независимой выборке сценариев, т. е. это не переобучение на сценариях.
Точная LP-модель решается за десятки миллисекунд и даёт двойственные цены мощностей «бесплатно».
